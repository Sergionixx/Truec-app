# Bundled example photographs

interface (`src/services/api.ts`, `src/App.tsx`, `src/components/PublishProductModal.tsx`).
They are illustrative stock photos, not photos of actual seller listings.
600 × 600 JPEGs are bundled so the native demo works without a network connection.
